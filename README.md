# 📁 Portfolio Web – Práctica de Diseño de Interfaces

## 📌 Descripción
Este repositorio contiene una **práctica académica** que consiste en el desarrollo de un **portfolio personal**, aplicando los conocimientos adquiridos en la asignatura de **Diseño de Interfaces** durante el curso del **Grado Superior en Desarrollo de Aplicaciones Web (DAW)**.

El objetivo principal del proyecto es diseñar y maquetar una interfaz web atractiva, clara y funcional, siguiendo buenas prácticas de diseño y usabilidad.

## 🎯 Objetivos del proyecto
- Aplicar los principios básicos de **diseño de interfaces**.
- Desarrollar una estructura web semántica.
- Crear un diseño visual coherente y adaptable.
- Mejorar la experiencia de usuario (UX).
- Consolidar conocimientos de **HTML y CSS**.

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **CSS3**

## 📂 Contenido del portfolio
El portfolio incluye secciones como:
- Presentación personal
- Proyectos o trabajos realizados
- Información de contacto
- Diseño visual coherente y responsive

## 🎓 Contexto académico
Proyecto realizado como parte de las prácticas de la asignatura **Diseño de Interfaces**, correspondiente al **Grado Superior en Desarrollo de Aplicaciones Web**.
